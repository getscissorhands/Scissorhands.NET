# Docs

The navigation groups pages using their slugs. Expand Docs to find
[Quickstart](docs/quickstart) and the non-clickable Deployment group.
Deployment has no page of its own; it appears because
[GitHub Pages](docs/deployment/github-pages) is visible in navigation.

Each page opts in with `show_in_navigation: true`. Hiding this page from navigation
also hides its descendants, without removing any generated pages.
