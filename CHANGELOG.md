# Changelog

Published release notes and package artifacts are maintained in
[GitHub Releases](https://github.com/getscissorhands/Scissorhands.NET/releases).
Use the release matching your installed package version; this file is an index,
not a reconstructed release history.

## vNext Development and Migration

The `vnext` branch is the current development line. Consult the
[vNext documentation handoff](docs/website-documentation.md) for documented
behavior and the [migration guide](docs/website-documentation.md#upgrading-to-vnext)
for breaking changes and upgrade instructions.

Branch documentation can describe changes that are not yet in a published
package. Check the corresponding release notes before upgrading.
